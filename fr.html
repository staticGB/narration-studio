Narration Studio: Français (French)

French has only one voice in Kokoro, so every character on this page sounds the same.

Cast

Press Preview on any row to hear that voice. Lines without a character name are read by the Narrator.

Script

Directions: what you can write in the script
Name: line

Character speaks the line. Lines without a name use the Narrator. Use the buttons above the text box to add one.

[pause 1.5]

Silence for that many seconds, on its own line.

[overlap] Name: line

The line starts before the previous one ends. [overlap 1] starts it 1 second early (default 0.6).

blank line

A short pause between paragraphs.

[anything else]

Other bracketed text is skipped, not read aloud.
